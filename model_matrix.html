Model 1: Snapshot Baseline Baseline Today's visit only
Current symptoms, age, medication state (ON/OFF), Levodopa dose		 Decision Trees (XGBoost)

Model 2: History Baseline Baseline Full visit history
All past clinical visits in chronological sequence		 Standard Memory Network (LSTM)
Remembers past visits, assuming visits happen at equal time intervals.		 Score at +12m & +24m Answers RQ1: Proves whether having patient visit history beats a single visit alone.
Model 3: Imaging Baseline Baseline Brain scan numbers only
DaTSCAN dopamine binding (SBR) + FreeSurfer MRI brain volumes		 Simple Neural Network

Model 4: Smart Time Model Deep Encoder Visit history + exact days between visits
Handles irregular intervals & missed check-ups		 Decaying Memory Network (GRU-D)
Fades older memories and handles gaps based on real elapsed days.		 Patient Health Vector Fixes real hospital flaws: Real patients don't visit on fixed intervals; GRU-D handles real-world gaps.
Model 5: Deep Brain Encoder Deep Encoder All brain scan measurements
DaTSCAN SBR + MRI subcortical brain volumes + cortical thickness		 Deep Residual Neural Network
Learns non-linear interactions across multiple brain structures.		 Brain Health Vector Feature compression: Compresses dozens of brain metrics into a clean summary for fusion.
Model 6: Early Fusion Multimodal Fusion Health Summary + Brain Summary glued side-by-side Joint Neural Network
Processes both summaries mixed together all at once from the beginning.		 Score at +12m & +24m Answers RQ2 (Option A): Tests whether simple feature concatenation is sufficient.
Model 7: Late Fusion Multimodal Fusion Clinical prediction + Brain prediction made separately first Smart Blending Judge
Lets each modality make an independent vote, then learns optimal trust weights.		 Score at +12m & +24m Answers RQ2 (Option B): Tests whether independent voting prevents noise leakage between modalities.
Model 8: Attention Fusion ⭐ Flagship Winner Both summaries fed into an interactive Attention Gate Dynamic Attention Network
Acts like an expert doctor: dynamically decides whether to trust symptoms or brain scans per patient.		 Score at +12m & +24m Answers RQ2 (Flagship): Most advanced model; provides explainable attention weights for each patient.
